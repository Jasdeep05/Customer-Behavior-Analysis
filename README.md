
# Customer Behavior Analysis

An end-to-end customer behavior analysis project using **Python, Pandas, PostgreSQL, SQL, and Power BI**.

## 📌 Project Overview

This project analyzes customer data to understand customer characteristics, purchasing patterns, and behavior. The project follows a complete data analytics workflow, starting with data cleaning and exploratory data analysis and ending with SQL analysis and an interactive Power BI dashboard.

## 🛠️ Tools & Technologies

* **Python**
* **Pandas**
* **Jupyter Notebook**
* **PostgreSQL**
* **SQL**
* **Power BI**

## 🔄 Project Workflow

```text
CSV Dataset
    ↓
Python & Pandas
    ↓
Data Cleaning & EDA
    ↓
PostgreSQL
    ↓
SQL Analysis
    ↓
Power BI Dashboard
```

## 🔍 Analysis Performed

### Python & EDA

* Dataset exploration
* Data type checking
* Missing value analysis
* Duplicate checking
* Data cleaning
* Statistical analysis
* Customer behavior exploration

### SQL & PostgreSQL

* Stored cleaned data in PostgreSQL
* Performed SQL queries for customer analysis
* Calculated important customer metrics
* Analyzed customer patterns and categories

### Power BI

* Created an interactive dashboard
* Developed KPI cards and visualizations
* Presented customer behavior and purchasing insights
